# Лабораторная работа №7: Навигация. Адаптив под разный формат экрана

## Цель работы
Научиться реализовывать навигацию в приложениях, используя Jetpack Navigation Compose, и адаптировать интерфейс приложения под широкий формат экрана (планшеты, альбомная ориентация).

## Выполненные задания

### Задание 1: Приложение Lunch Tray (Навигация)
В стартовый проект добавлена навигация между экранами оформления заказа.
* Создан `enum class LunchTrayScreen`, содержащий константы маршрутов (`route`) и строковые ресурсы заголовков (`title`) для всех пяти экранов.
* Настроен контроллер навигации (`rememberNavController`) и хост (`NavHost`).
* Реализован `TopAppBar`, который динамически считывает текущий маршрут и отображает соответствующий заголовок.
* Кнопка обратной навигации (стрелка) отображается в `TopAppBar` только в том случае, если пользователь находится не на стартовом экране.
* Настроены переходы кнопок «Next» по цепочке: Start -> Entree -> Side Dish -> Accompaniment -> Checkout.
* Кнопки «Cancel» и «Submit» реализуют возврат на стартовый экран с полной очисткой стека навигации (`popUpTo` с параметром `inclusive = true`), а также сбрасывают состояние заказа во ViewModel.

### Задание 2: Приложение My City (Адаптив и MVVM)
Создано приложение-справочник интересных мест города с категориями (Рестораны, Парки, Кофейни, Кинотеатры, Торговые центры).
* Создана модель данных `Place` и источник данных `DataSource`, содержащий по несколько мест.
* Реализован `MyCityViewModel`, который хранит данные с использованием `MutableStateFlow` и предоставляет их через `StateFlow` (соблюдение паттерна UDF).
* Настроена навигация через `NavHost` для перехода от списка категорий к списку мест.
* **Реализован адаптивный интерфейс:** при помощи `currentWindowAdaptiveInfo()` определяется размер окна. На компактных экранах (смартфон) используется стандартная навигация (смена экранов). На расширенных экранах (планшет, альбомная ориентация) автоматически активируется макет **List-Detail** (две панели: слева список категорий, справа — содержимое выбранной категории).
